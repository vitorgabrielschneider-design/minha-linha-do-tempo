# Minha linha do tempo

Uma página estática, responsiva e sem dependências de JavaScript para apresentar uma história em formato de linha do tempo.

## Como usar

Abra `index.html` no navegador. Para personalizar, edite os textos dos eventos no HTML e ajuste as cores e tipografia em `styles.css`.

## Estrutura

- `index.html` — conteúdo e estrutura semântica da página.
- `styles.css` — layout, tipografia, cores e responsividade.
